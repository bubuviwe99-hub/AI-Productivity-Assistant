# Aura Studio AI

Create a premium, modern, responsive website for a luxury beauty parlour offering Makeup, Lashes, Massages, Hair Extensions, and Nails.

Use the attached images as the visual reference. The design should be elegant, feminine, calming, and sophisticated, using:

• Blush/dusty pink

• Soft mauve

• Ivory/cream

• Champagne/rose gold

• Muted teal/sage

• Deep blue-green

Use elegant serif headings, clean sans-serif body text, thin gold borders, circular/overlapping shapes, soft shadows, subtle gradients, and generous whitespace. Avoid an overly pink or generic salon aesthetic.

### Main Pages

• Home

• Services

• Book Appointment

• AI Assistant

• AI Planner

• Email Generator

• Contact

### Key Features

**1. AI Beauty Assistant**

Create an interactive chatbot that helps clients:

- Choose the right service

- Answer salon FAQs

- Recommend makeup, lashes, nails, massages, and hair extensions

- Explain service duration/preparation

- Guide users toward booking

Include suggested prompts, chat history, typing states, and a “Book this service” CTA.

**2. AI Task Planner**

Create a salon staff dashboard where users can:

- Generate daily/weekly schedules from natural-language prompts

- Prioritize tasks as Urgent, High, Medium, or Low

- Manage appointments and staff tasks

- Detect scheduling conflicts

- View tasks in a calendar/timeline

Example: “Create tomorrow’s schedule and prioritize bridal clients.”

**3. Smart Email Generator**

Allow staff to generate professional salon emails by entering:

- Purpose

- Recipient

- Key information

- Tone: Formal, Friendly, Persuasive, Warm

Include appointment reminders, confirmations, cancellations, promotions, and follow-ups. Add Copy, Edit, and Regenerate buttons.

### Booking

Create a simple multi-step booking flow:

Service → Date → Time → Client Details → Confirmation.

### Responsible AI

Clearly label AI-generated content as suggestions. Require confirmation before sending emails or changing appointments. Protect client information and avoid medical/diagnostic advice.

### UX & Presentation

Make everything fully responsive with polished animations, loading/error states, accessible controls, and realistic demo data.

The overall concept should feel like:

**“Luxury beauty studio meets intelligent AI business assistant.”**

Prioritize functionality, innovation, responsible AI, and a polished presentation suitable for a hackathon, university project, or business pitch.
